# MVP 历史基线

> 本文保留早期 MVP 的范围记录，不代表 0.9.12 当前完整能力。当前功能与风险以根目录 `README.md` 和 `HANDOFF.md` 为准。

最初 MVP 目标是验证以下闭环：

1. Windows 客户端读取 TXT 话术并拆分为句子。
2. 客户端连接云端 TTS，选择参考音色并逐句生成。
3. 客户端缓存音频并输出到指定播放设备。
4. Mock 后端允许在没有 GPU 的环境完成开发测试。

当前版本已经在此基础上增加逐句参考音频、自动匹配、20 句滚动缓存、暂停/继续、插播、本地批量合成、窗口持久化和升级机制等能力。

仍不属于项目范围：弹幕礼物接入、数字人驱动、自动开播、麦克风采集和 LLM 自动改写。
