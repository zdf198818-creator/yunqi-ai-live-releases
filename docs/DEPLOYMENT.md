# 云端部署

当前客户端目标版本为 0.9.12。容器镜像标签应使用明确版本（例如 `0.9.12`），不要继续使用历史示例 `0.1.0` 或浮动标签作为唯一生产标识。

## 服务组成

- TTS API：默认 8000。
- TTS 启动器：默认 7860，仅用于人工启动/停止和查看日志。
- Qwen3-TTS 模型、SQLite 音色元数据和参考音频持久卷。

## 部署原则

1. 模型和运行依赖固化在私有镜像中，运行数据挂载到独立持久卷。
2. API 服务只监听所需接口；8000 和 7860 不直接暴露公网。
3. 通过受控反向代理提供 TLS，并设置访问控制、防火墙和请求限制。
4. 从密钥管理或实例环境注入认证值，不写入镜像、仓库、启动脚本或文档。
5. `.env.example` 的占位值不会启用安全认证，生产部署必须替换。
6. 启动器 7860 当前没有独立认证；只能放在可信内网，或由云平台控制台访问。
7. 持久化音色数据库与音频目录，升级镜像时不得删除。

## 安装与启动

```bash
python -m venv .venv
.venv/bin/python -m pip install -e '.[server,gpu]'
.venv/bin/python -m uvicorn ailive.server.app:app --host 0.0.0.0 --port 8000
```

启动器：

```bash
.venv/bin/python -m ailive.launcher
```

模型路径、设备和认证值必须通过环境变量注入。仓库 `deploy/` 中的辅助脚本使用前必须核对模型目录、Python 环境、端口和认证占位值，不应原样作为生产密钥配置。

## 发布前验证

- `GET /health` 正常，客户端完成至少 100 句连续生成播放。
- 记录真实模型 RTF、GPU 显存、错误率和缓存水位。
- 模拟网络中断、服务重启和客户端重连。
- 验证关闭公网匿名访问后客户端仍能认证连接。
- 验证实例重启后模型、数据库和音色文件完整。
- 检查日志不含令牌、密码、私钥或不必要的参考音频内容。

## 镜像发布

先发布私有镜像并完成验收；成熟后再复制为公开社区镜像。公开镜像不得包含用户参考音频、数据库、环境文件、SSH 私钥或任何真实凭据。
