# 云祺 AI 直播协议

当前客户端发布版本：0.9.12。服务端默认监听 8000；云端 TTS 启动器默认监听 7860。

## 认证

服务端支持可选令牌认证。只有部署方设置了非占位认证值时才启用保护；示例配置中的占位值不等于已启用认证。

- HTTP 请求使用 `Authorization: Bearer <token>`。
- WebSocket 当前兼容查询参数令牌。公网环境建议改为短期票据或建立连接后的安全认证，避免令牌进入代理日志。
- 文档、日志和错误信息不得保存真实令牌。

## HTTP

- 健康检查：`GET /health`
- 音色列表：`GET /voices`
- 上传音色：`POST /voices`

音色上传大小上限为 50 MB。当前代码仍需补充可靠的音频解码与 MIME 验证。

## WebSocket 合成

客户端连接 WebSocket 合成端点后发送 JSON 请求，关键字段包括待合成文本、已同步的音色标识、参考音频文案、语速和随机性模式。

- `normal`：正常采样。
- `low`：降低随机性，语气更稳定。
- `off`：使用稳定种子和保守采样，尽量固定；不承诺不同硬件和运行环境下字节级一致。

服务端返回音频数据和结束/错误消息，客户端把完整 WAV 放入播放队列。

## 缓存语义

- “开始播放最低缓存”允许 1–10 句，默认 3 句。
- 直播开始后滚动缓存目标为 20 句。
- 暂停播放不应暂停云端生成，直到缓存达到目标或话术结束。
- 停止必须取消本轮请求并清理运行态；再次启动应建立新的播放会话。

## 文本语法

- `#500#`：插入 500 毫秒停顿，单次最大 60,000 毫秒。
- `[甲|乙]` 或 `【甲|乙】`：从选项中选择一个用于生成。
- 本地批量合成文件名会移除控制符号和 Windows 文件名非法字符，并处理重名。

## 错误处理现状

本地批量合成对单句最多尝试3次，仍失败则跳过。直播流也会对同一句自动重连并最多尝试3次；最终失败时只跳过当前句，保留已生成缓存并继续后续话术。长时间断网的指数退避恢复仍待完善。
